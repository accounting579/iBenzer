## Critical blockers
List only items that can cause rejection, missed deadline, or incorrect submission.

## Final submission checklist
- [ ] All mandatory forms complete
- [ ] All required signatures/initials complete
- [ ] Pricing/bid lines verified
- [ ] Manufacturer/catalog/spec support included
- [ ] Addenda checked/acknowledged
- [ ] Submission package/method verified
- [ ] Tracker updated with verified status

## Next action
State only the next concrete action(s), in priority order.

If the user asks “what is still missing?”, lead with missing/blocking items instead of repeating completed work.
