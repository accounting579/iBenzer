# iBenzer Operations Plugins

Private source repository for the iBenzer Accounting and Admin plugins.

## Change-control rule

1. Record a demonstrated error in the shared AI error library.
2. Classify it as a missing rule or an execution failure.
3. Obtain human confirmation of the corrected rule.
4. Update the affected plugin or skill, then commit the change with a meaningful version note.
5. Sync the Workspace marketplace and verify the new rule on a real task.

The shared Google Drive error library remains the live record; packaged rules are the approved, released version used by the plugins.
